# Every UVM ioctl number is a bare integer (uvm_ioctl.h: UVM_IOCTL_BASE(i) = i),
# so unlike the _IOWR('F', nr, struct) escape path nothing in the request encodes
# the argument size.  The driver still copies exactly sizeof(struct) to and from
# user space (UVM_ROUTE_CMD_STACK, uvm_api.h), and a short user buffer is read
# past its end, so the modelled size must equal the C sizeof.  The [size[N]]
# attributes below turn that invariant into a compile-time error in syz-sysgen
# instead of a silently truncated copy.  Layouts and sizes come from the real
# headers under open-gpu-kernel-modules/kernel-open/nvidia-uvm.
